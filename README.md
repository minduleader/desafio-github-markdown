# Títulos

Títulos são os headers (do html) de um texto e alteram a proporção e aparência de um texto. Para usar, basta por "#" na primeira linha do texto.
Exemplo: 
"# Oi"
# OI
## OI
### OI

Para por em negrito, coloque a palavra entre "**", dois antes e dois depois.
Exemplo
"**Batata doce**"
**Batata doce**
